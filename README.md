A tiny, exact interpreter for make.fun's tiny stack ISA. `main.ts` runs all 40 programs of a set in one run and writes each program's stdout and exit code. It follows the reference VM exactly: 32-bit wrapping arithmetic, all ten trap codes, step and output limits. Practice set: 1,000,000 points (40/40), vs 670,000 for the house baseline plain-vm 1.0.0.
